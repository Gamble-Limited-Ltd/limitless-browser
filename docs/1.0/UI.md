# Limitless 1.0: UI plan

Slice S6 (wave 4), after design round 2 (section 9). Picks come from the design artifact
(https://claude.ai/artifact/P1arJs1FYrMrCoBmR5VQ2h). Principles from Boss: it must look real and stay that way once
implemented; refined, slow and precise motion; no overlapping text; clean formatting; anti-AI-slop checks (Hallmark and
Impeccable) on every new screen; works at 1366x768 and scales to 1440p.

## 1. Rules that still apply
- Theme tokens only (`theme/themes.css` generated by `scripts/gen-themes.py`, mapping in `theme/chrome.css`); every new
  component reads `--lb-*` tokens. Body text and text on accent meet 4.5:1 in every theme.
- Upstream skins (Chrome, Brave, Firefox, Opera GX, Zen, Limitless+) are kept as they are and still override the themes
  (`html[data-lb-theme]:not([data-skin])`). New chrome must not break under a skin; under a skin, upstream chrome wins.
- All dynamic text through `textContent`. No em dashes in copy. Straight quotes.
- `prefers-reduced-motion`: every animation collapses to a 150 ms opacity change or none.
- Motion: 160 to 240 ms, `cubic-bezier(.2,.7,.2,1)` for entrances, nothing bouncy (Boss: slow and precise).

## 2. Toolbar and menu (picked: classic tabs, Limitless menu)
- **Visible:** Back, Forward, Reload/Stop (one button), the address bar (bookmark star and ad-block shield inside its
  right end), Extensions, the Limitless menu button. Nothing else.
- **Moved into the menu:** New tab, History (`Alt+H`), Bookmarks (and "Show bookmarks bar"), Theme (the drawer),
  Fullscreen (`F11` / `Alt+K`), Downloads (S8), Membership, Report a problem, Settings, Developer mode.
- **Developer mode** (Settings > General, `limitless:devmode:v1`, default off): shows the logs panel button
  (`#devToggle`, `Ctrl+Shift+I`), element inspector (`#codeBtn`), metrics (`#metricsBtn`) in the toolbar. Off: they are
  hidden and lazy-loaded only when turned on (`SPEED.md` 3.4). Keyboard shortcuts keep working.
- Menu header: the member's **name, then the number** (Boss's note on settings applies here too), tier and standing.
- Existing ids stay where code depends on them (`#back`, `#fwd`, `#reload`, `#stop`, `#home`, `#settingsBtn`, ...): the
  buttons move into the menu as menu items with the same ids or the handlers are re-bound; `patcher.html` checked.

## 3. Tabs, address bar, loading
3.1 **Classic tabs** (default): today's strip restyled per theme. **Vertical tabs** (picked as well): Settings >
Appearance "Tab layout: Top / Side". Side rail 220 px, collapses to 52 px icons below 1200 px window width and by toggle;
groups "Today" and "Pinned". Stored `limitless:tablayout:v1`.
3.2 **Address bar:** full URL with the domain picked out (scheme and path in muted colour, registrable domain in body
colour, lock icon), monospace, ellipsis on the path. Focus selects all and shows the raw URL.
3.3 **Progress bar:** 2 px under the address bar, accent to accent2 gradient, soft glow, real progress (`SPEED.md` 2.4),
fades out 200 ms after `shown`.
3.4 **Page error card** (picked "calm themed card"): Orbit mark in muted colour, one plain sentence title ("This site is
not answering"), one sentence of cause, one primary action (Try again), a secondary (Report a problem, or "Use another
relay" when relevant), "Technical details" folded (code, relay, stream, port). Replaces the current error page template
for timeouts, DNS failures, blocked ports, relay down, TLS errors.

## 4. Start page and splash
- **Member card** on the start page (picked): name and number ("Alex Morgan · No. 047"), tier, "since November 2026";
  opens Settings > Membership.
- **Broadcast notice** (picked "engraved bulletin"): small-caps NOTICE label, one or two serif lines, date, dismiss;
  under the clock; from `/_lb/me` `notices[]`; dismissed ids remembered per device.
- **Splash** (picked, with Boss's note): Orbit mark draws in, then the member's **name** as the main line, with the
  number as small footer text ("No. 047"), hairline progress. Hides as soon as the start page is interactive. Before the
  first `/_lb/me` answer (or on a cold start), the name is taken from a per-device cache (`limitless:me:v1`, name and number
  only); if none, the splash shows the mark and wordmark only.

## 5. Settings in six groups (picked)
| Group | Contains (from today's 13 sections) |
|---|---|
| General | search engine, start page and shortcuts (`homescreen`), language, keyboard shortcuts, tab sleeping, developer mode |
| Appearance | themes grid, Light/Dark/Auto, marks, tab layout, skins, wallpaper (skins only) |
| Privacy and data | privacy toggles, ad and tracker blocking with allowlist, cache (`cache`), files and media, clear data |
| Connection | relay status and choice, third-party relays (`fallback`), parallel requests, sockets, multi-relay, data saver |
| Membership | name then number, tier, standing, certificate (download, code), nominations, charter version and link to the Rules |
| About | version, What's new, source and licences (AGPL source link stays), legal links, Admin panel link (owner only) |
- Opens on General (today it opens on Skins). The tutorial section is removed (ceremony tour replaces it).
- Each moved control keeps its storage key; only the markup moves.

## 7. Visual system additions
7.1 **Custom icon set:** about 30 thin-line SVG icons (1.6 px stroke at 24 px, round caps) matching the Orbit mark, as one
SVG sprite in `theme/icons.svg`; used in the toolbar, menu, settings and error cards. Font Awesome 6.7.2 stays for upstream
and rare spots (and for skins).
7.2 **Prime theme:** Crimson and obsidian (favourite) with Obsidian and platinum as the alternative to show again in round 2.
Draft tokens from the artifact: bg `#050506`, surf `#0e0e11`, fg `#e4e6ea`, mut `#8b8e96`, line `#24252b`, acc `#e0304b`,
acc2 `#f0f1f4`, on `#050506`. Text on the crimson accent with `#050506` is about 4.55:1 (computed), so it passes narrowly;
round 2 confirms every pair. Dark only, like Vault. Added through `scripts/gen-themes.py` + `docs/DESIGN.md` + `THEMES`
+ the theme grid (locked tile with a seal for lower tiers) + `tests/e2e/themes.spec.js`.
7.3 **Vault:** locked to Cardinal and Prime now; redesign optional in round 2.
7.4 **Tier marks** (picked "rings"): Ordinal = Orbit; Cardinal = Orbit with a silver outer ring; Prime = Orbit in an
obsidian disc with a fine dotted ice ring. Symbols `lb-mk-tier-ordinal|cardinal|prime` in `#lbMarks`.
7.5 **Fonts:** Pinyon Script and Cormorant Garamond added to `theme/fonts/` (OFL, licences next to them), used only in
the ceremony, certificate, notices and member card numerals. Fetched by `scripts/fetch-fonts.py`.
7.6 **Extensions:** curated "Limitless Collection" (a short list Boss approves) shown first; others installable but marked
"Unreviewed"; the extension system lazy-loads on first use.
7.7 **Sounds:** ceremony only (reveal chime, seal press), synthesised with Web Audio, respect system mute and reduced motion.

## 8. Accessibility and layout targets
- Window sizes tested: 1366x768 (school Chromebook), 1440x900, 1920x1080, 2560x1440. No horizontal scroll, no clipped or
  overlapping text (checked automatically, `TESTING.md` 3).
- Every icon-only button gets an `aria-label` (today 18 of 334 buttons have one); visible `:focus-visible` ring in every
  theme; Esc closes the menu, panels and dialogs; the menu is keyboard navigable (arrow keys).
