- Other favourites: `chrome-classic`, `chrome-vertical`, `notice-formal`, `notice-letter`, `bulletin-engraved`. Maybe: `error-calm`, `notice-void`, `step5-card`, `step5-cert`, wording sets (plain, quiet, student, none chosen yet).
