# Limitless Browser 0.3.0: release record

- **Lane:** Minor (new systems: public relays only, boot access check, blocklist, service worker, page pipeline). Gates: `npm test`, stack rehearsal, trial run (relay-off rehearsal, fault suite), speed gate, smoke check, then a 24 h hold.
- **Pinned sha:** the `main` commit that holds this record (fast-forward of `release/0.3.0`; the sha is in the deploy command Claude pastes in chat).
- **Rollback sha:** `c88ce5e` (0.2.3, live since 2026-11-08). `cd ~/Browser && ./deploy.sh c88ce5e`. It brings the home relay back (the old compose has no profile) and `deploy.sh` injects the service worker stub so installed 0.3.0 workers remove themselves.
- **Built:** 2026-11-10 to 2026-11-15 (S1, S2, S3, fetch core reused from `release/1.0.0`; relay off, blocklist, faults, libcurl 0.7.5 and font preload built 2026-11-14/15). Plan: `docs/1.0/PLAN.md` 0.2b, `docs/1.0/SPEED.md`. Release notes and host steps: `docs/1.0/RELEASE-0.3.0-NOTES.md`.

## What changed
- Home relay off: public relays only until 1.0 (`relay` and `dns` under a compose profile, nginx answers 410 on `/wisp/`, client switch `ownRelay` false). Dead relays dropped (probe 2026-11-15, 7 alive).
- Boot access check, fail closed (no libcurl session until `version.json` answers 200).
- Speed work: app script and WASM out of `index.html`, service worker app shell, page pipeline, lazy images, progress bar, Data saver, rewrite cache, instant Back/Forward, tab sleeping, CSS url() rewrite, font preload.
- Fetch core: error classes, per-request deadlines, transfer of binary bodies, relay-drop detection on the shared connection, truncated bodies fail as reset.
- Blocklist: HaGeZi Multi LIGHT (GPL-3.0) host-suffix matcher, downloaded once the fetch queue is idle.
- libcurl.js 0.7.5.
- Server: 5 s auth cache at nginx, `Server-Timing` and `X-LB-T` aggregates.
- Gate image is rebuilt from `~/limitless-gate` main (`0bc84f7`, includes Wayfinder W3a, which falls back to the old behaviour without its hosts file).

- chromium: fx-frames cold shown 328 to 453 ms (+38 %), cold load 604 to 729 (+21 %), warm load 438 to 561 (+28 %).
