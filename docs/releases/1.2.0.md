## What changed
- **Speed land** (`slice/1.2-speed-land`): ES modules as `blob:` URLs (the 2.6 MB `data:` module that froze Steam), the rewriter joins edits once and walks the tree once,
  size-scaled Worker timeouts, CSS fonts and images as `blob:` URLs (one font file per face, Latin subsets), direct-load fixes, memory budget by device, the `import()`
  helper, fetch queue priority, the Site Refused card, script de-duplication, the 204/205/304 frame fetch fix. Harness files (`profile`, `sites-games`, `sites-media`) ported.
- **Popup bridge** (`slice/1.2-imglane-google`, `features.popupBridge`, default on): `window.open` gets a second proxied tab with a working `window.opener` and relayed
  `postMessage`; a page-added CSP meta (Trusted Types) is kept inert. Google's own login stays best effort.
- **Built, OFF:** `features.curlWorker` (libcurl in a Worker, slice 1 only), `features.swDoc` (service worker document lane), `features.imgLane` (native image lane,
  needs the VPS container and the HALL privacy line). Nothing about them is announced to members.
- **Gate:** `GATE_MODE=img` image server (`src/img/`, sharp), tests only. Home gate code paths unchanged.
- **Merge fixes:** `LB_features` key list now carries every switch (the speed-land branch had left `blocklistYield` to `scriptDedup` out, so `version.json` could not turn them
  off); `lbFrameGuard` (popup slice) no longer treats a `swDoc` lane document as a native escape (found by `swdoc.spec.js` on the merged tree, see below).

### Failures found and fixed
1. **`swdoc.spec.js` "on: the frame is served from /~lb/doc/..."** failed on the merged tree (and 3 of 3 on `slice/1.2-swcurl` run alone under load). Cause: `lbFrameGuard`, added by the popup slice,
   treats a frame whose URL is not `blob:` as a native page escape and re-routes it through `go()`, so the lane document `/~lb/doc/...` was fetched through the proxy and replaced.
   Fix (`e49050f`): the guard accepts `LB_swDoc.isDoc(landed)`. The spec fails before and passes 25 of 25 (5 repeats) after. The switch ships off, so no member could hit it.
2. **Visual `luxury/dark` start and menu shots**: baseline predated the WP3 hairline bulletin and the test left AM/PM to the real clock (the baseline was taken in the evening). Failed on 1.1.0 too.
   Fix (`d3c9ba5`): clock suffix pinned to AM in that test, two baselines refreshed.
3. **`chromebook.spec.js`** (CPU throttle ratio must exceed 2): 1.99 and 1.81 under load, passed 3 of 3 in a rerun with a quieter machine. Flake, no change made, threshold untouched.
