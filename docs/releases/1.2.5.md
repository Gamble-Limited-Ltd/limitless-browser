## What changed
- **L1 lockdown CSP (`features.lockdown`, build `LB_FEATURE_LOCKDOWN`, default false):** `lbFrameCsp()` feeds both frame CSP metas; with the switch on the frame may only load from our origin, `blob:` and `data:`, and violations are counted per host in `lbRw.stats.cspBlocked` (so the real-site run can list what still goes direct). Off: the CSP is the old `frame-src blob: data: about:;`.
- **L3 rewriter gaps (`features.rwGaps`, build `LB_FEATURE_RWGAPS`, default false):** `setAttribute` of `srcset` and `new Audio(url)`, `setAttribute` of `src` on a script and `href` on a preload link, and CSS `url()` and `@import` written by script (`setProperty`, style `textContent`) are routed through the proxy. Off: unchanged.
- Test notes: `tests/e2e/lockdown.spec.js`, `tests/e2e/rwgaps.spec.js`; `tests/stack/sites.spec.js` saves `cspBlocked` and the recent list per site run.
- Not in this release: the switches are turned on later (plan TL-1 release B, a Minor, after a real-site run).
