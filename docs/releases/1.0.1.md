## What changed
- **Everyone sees the ceremony and picks a number (Boss):** the owner is no longer let through without the ceremony (keeps No. 0000, never suspended or removed). The 8 pre-1.0 accounts were numbered by the migration; their numbers are cleared (only unsigned, non-owner rows) so they choose in the ceremony. New accounts already chose their own.
- **Themes did not change colours after the update:** the service worker served `/theme/*` stale-while-revalidate, so the first load after a release used the last release's `themes.css` (no rules for the new themes). Theme CSS is now network first, cached copy only offline. The 1.0.0 worker still answers the first load after this deploy the old way; a second load (or the update banner's Reload) is clean, and from then on every release is.
- **Admin Usage card:** the 0.2.0 per-user limits editor and the env "Default: ..." line are gone (limits come from plans; one member's overrides are in the member profile).
