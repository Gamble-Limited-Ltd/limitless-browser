## What changed
- **YouTube blocked (`features.ytBlock`, build default true, `LB_FEATURE_YTBLOCK`):** youtube.com, youtu.be, youtube-nocookie.com, googlevideo.com, ytimg.com and subdomains are refused for every request and tier, before the ad-block switch and the allowlist. Navigation shows the card "YouTube is not available in Limitless." Embeds and thumbnails on other sites are blocked too. Gate: `isBlockedHost` (`src/sites.ts`), CONNECT answered with CLOSE `BLOCKED` (0x48) for every member including the owner; counter `wisp_blocked_host` only, no hostname stored or logged; kill switch `YT_BLOCK=off`.
- **Google sign-in card (`features.googleSignin`, build default true since 1.2.2, `LB_FEATURE_GOOGLESIGNIN`):** `accounts.google.com` sign-in paths (ServiceLogin, signin, v3/signin, AccountChooser, InteractiveLogin, `/o/oauth2/`) show a plain card instead of fetching the page: why Google blocks it, what works signed out (Search, Maps, shared Docs links), and "Open outside Limitless" (`window.open(url, '_blank', 'noopener')`, matcher-checked).
- **Carried, OFF:** G1 visible-first images (`features.visibleFirst`, build default false). Code is in, inert while off.
- Not in this release: N8 (sockets stay 4), N7, N4, L1, L3.

## Player note (= CHANGELOG 1.2.2)
- YouTube is not available in Limitless on any plan. Opening it shows a short note instead, and YouTube videos and pictures inside other sites are blocked too.
- Google sign-in pages now show a plain explanation instead of a broken page: Google blocks sign-in through any service in the middle, on purpose. Search, Maps and shared Docs links still work signed out, and an "Open outside Limitless" button opens the sign-in in a normal tab. This includes "Sign in with Google" buttons on other sites.
