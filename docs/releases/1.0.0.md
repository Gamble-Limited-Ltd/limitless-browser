## What changed
- Our relay is back, on the VPS (`relay.taps-holdings.org`, DNS only, not through Cloudflare): short-lived signed tokens from home lbgate, fair share by plan, byte counts synced home every second. Public relays stay the fallback. Build defaults `LB_FEATURE_OWNRELAY=true`, `LB_FEATURE_OWNSOCKETS=4`.
- Membership: numbers, charter, welcome ceremony, certificates, standing (suspend, remove), public verify status (no names). Legal names are stored encrypted with `MEMBER_DATA_KEY`.
- Every GLL ID gets the free Ordinal tier (GLL ID client `limitless-browser` switched to open; sign-in stays required).
- New UI: Limitless menu, settings groups, 13 themes (5 paid), calm error cards, address bar domain view, vertical tabs, tab cap for Ordinal.
- Paid tiers engine: plans page, account panel, request form (queues a copy to the support inbox), trials, top-ups, Load Now, transfer brake. `plans_open` ships OFF.
- Downloads panel; Report a problem; admin queue and load-time chart.
- Speed and data savings (PLAN 0.2d, built 2026-11-15 night): relay fair-share fix, 50 Mbit/s per-socket ceiling, download class (own socket, own allowance when the plan has one, pages first, 4429 when used up), split downloads by plan (1/2/4/8 parts), video hosts on their own socket with per-plan relay speed caps (2.5/5/10 Mbit/s for 480p/720p/1080p) plus app-side player caps, one video at a time, Data saver at 90 %, data meter, per-site report kept on the device, HaGeZi Normal blocklist, AVIF/WebP Accept, only the first 6 images pre-warmed, prefetch hints dropped, files over 200 MB through public relays (member setting, off). Compression was already on (libcurl.js sends gzip/br). Server keeps daily bytes per site per plan, no member link, 30 days (`SITE_STATS`).
